## 8. D3의 동시 출현 규칙은 품목 복원에 유효했다

## 13. 수집은 검증·갱신·만료까지 하나의 흐름이다

정해진 판매처에서 상품명·가격·품절·배송비·옵션을 제한적으로 추출한다. 재수집 실패 때 과거 가격을 최신 값으로 표시하지 않는다. 수집 유효기간과 실제 판매 종료 일시를 별도로 해석한다. 공개 전체 상품 크롤링을 완료한 것으로 설명하지 않는다.

## 14. 실제 가격 변경을 반영해 비교 결과를 갱신했다

## 15. RAG와 현재 DB 조회를 결합한 챗봇

## 33. 부록 · 요구사항정의서 1–8

signup_01 회원가입
이메일·비밀번호 또는 카카오 계정으로 일반 회원에 가입하며 14세 이상 이용 동의와 이용약관·개인정보 처리 동의를 필수로 받는다. 다른 회원에게 이미 연결된 소셜 계정은 연결할 수 없으며 계정을 자동으로 합치지 않는다.

login_01 로그인
이메일·비밀번호 또는 연결된 카카오 계정으로 로그인한다. 인증에 실패하거나 사용할 수 없는 계정이면 이를 안내하고 입력 내용을 유지하며, 로그인 후에는 로그인 전에 보던 화면으로 돌아가되 저장·관심·글쓰기 등 회원 행동을 자동 실행하지 않는다.

logout_01 로그아웃
회원은 계정 관리에서 로그아웃한다. 현재 로그인 세션을 종료하고 비회원 상태의 첫 화면으로 이동한다.

recovery_01 복구코드 발급·비밀번호 재설정
이메일 가입 시 복구코드를 표시해 보관 여부를 확인받고, 회원은 현재 비밀번호 확인 후 새 복구코드를 재발급받으며 이전 코드는 폐기한다. 이메일·유효한 복구코드·새 비밀번호로 비밀번호를 변경하면 기존 로그인 세션과 복구코드를 폐기하고 새 복구코드를 안내한 뒤 다시 로그인하도록 한다.

mypage_01 마이페이지 조회
비회원에게 로그인·회원가입을 안내한다. 회원에게 내가 공유한 공구, 작성한 수요 글, 관심 표시한 수요, 저장한 육아템, 관심 설정, 계정 관리 메뉴를 제공하고 관리자에게만 운영 메뉴를 표시한다.

account_01 닉네임 변경
글과 댓글에 표시할 닉네임을 2~30자로 변경한다. 변경 결과를 계정과 작성자 표시에 반영하며 연결된 소셜 서비스의 프로필 이름은 변경하지 않는다.

account_02 회원 탈퇴와 기록 삭제
현재 비밀번호 또는 소셜 계정 재인증으로 본인을 확인하고 삭제 범위와 복구 불가 여부를 확인받는다. 본인 작성·활동 기록과 인증 수단을 삭제하고, 남는 식별 기록의 범위를 안내한다.

main_01 첫 화면과 메뉴 구성
첫 화면에는 마감이 가까운 진행 중 공구와 관심이 많은 공구 수요를 먼저 보여준다. 로그인 없이 공구 찾기·공구 수요·육아템 정보·단가 비교를 이용하며 하단 메뉴는 공구 찾기, 공구 수요, 단가 비교, 저장, 마이로 구성한다.

## 34. 부록 · 요구사항정의서 9–16

groupbuy_01 진행 중 공구 목록·검색

groupbuy_03 공구 정보 공유·관리

공구 정보·수요 글·댓글·신고 등의 등록·수정 시각과 운영 처리 시각을 기록한다. 화면의 작성·접수 시각과 출처 확인 시각은 한국 시간 기준으로 표시한다.

a11y_01 화면 크기·키보드 이용
모바일과 PC에서 주요 메뉴·입력·목록을 이용할 수 있도록 화면을 배치한다. 입력 항목의 이름, 키보드 초점, 오류·처리 상태를 제공하고 화면 이동 시 본문으로 접근할 수 있도록 한다.
