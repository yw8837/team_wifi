# 팀 협업 시트 개편 — 2026-11-04

대상은 기존 Google Sheets `Team_Wifi_FP`이며, KOTA와 법률절차길잡이의 업무 상태·기한·회의 결정 연결 구조를 참고했다. 참고 시트는 수정하지 않았다.

## 최종 사용 방식

- `팀원별 할 일`이 단일 입력 원본이다. A11:L29의 네이티브 표 `TeamWifiTasks`에 기존 9건과 최신 근거 기반 후속 업무 9건을 담았다.
- D:F의 이승현·최유정·최용우 체크박스로 담당을 정한다. 복수 선택은 공동 담당, 모두 해제하면 미배정이다. 담당자를 임의로 지정하지 않았다.
- C열 상태와 I열 우선순위는 네이티브 드롭다운 칩이다. 작은 화살표뿐 아니라 칩 본문을 눌러 선택할 수 있다. 확정 기한은 G열, 다음 행동은 H열에서 직접 수정한다.
- 상단에는 각 팀원의 미완료 업무 이름 최대 3개와 남은 건수·완료 건수가 나타난다. 추가 업무 수를 별도로 표시한다.
- 기존 `팀 할일` 탭은 `업무 현황`으로 바꾸고 원본에서 자동 계산한다. 자동 출력 부분은 경고 보호를 설정해 잘못된 직접 편집을 줄였다. 강제 접근 제한을 추가한 것은 아니다.
- 대시보드의 집계와 회의 확인 목록은 자동 갱신된다. 공동 담당은 각자의 현황에 포함되지만 전체 업무는 한 번만 집계한다.
- 회의록에 담당·연결 업무 번호·후속 기한·근거 링크를 추가했다. 10월 30일 원문과 미확정 일정은 보존했다. 새 현황 공유를 실제 회의에서 확정한 결정으로 표시하지 않았다.
- 처음 만든 `내 업무 수정` 링크와 공용 담당자 선택 방식은 사용자 피드백에 따라 제거했다. 수정하려고 별도 링크를 열 필요가 없다.

## 확인

- 라이브 시트의 73개 수식에서 계산 오류 없음. 표 메타데이터의 범위 A11:L29, 세 개 BOOLEAN 담당 열, 상태/우선순위 DROPDOWN, DATE 기한 열을 확인했다.
- 담당 체크박스 54개가 실제 Boolean 입력이다. Chrome 화면에서 체크박스를 한 번 눌러 담당자 목록 갱신을 확인했다.
- T01에 이승현·최유정을 함께 체크했을 때 양쪽 목록에 표시되고, 업무 현황에 두 이름이 연결되며, 미배정이 16→15로 감소하고 전체 미완료 16은 유지되는 것을 확인했다. 검증용 체크는 둘 다 원래 FALSE로 복원하고 다시 조회했다.
- 상태 칩의 본문 클릭으로 6개 상태 선택 목록이 열렸다. 실제 업무 상태는 바꾸지 않았다.
- 기존 9건의 번호·제목·상태와 8개 회의 원문을 보존했다. 기존 목표와 근거도 원본 표의 배경·근거 열에 보존했다.
- 초기 집계는 등록 18 / 완료 2 / 미완료 16 / 막힘 1 / 미배정 미완료 16이다. 이는 등록 업무 기준이며 제품 전체 완성률이 아니다. 이후 팀원의 입력으로 달라진다.
- Google 기본 표 변환은 표 위에 한 행을 추가했다. 갱신된 메타데이터를 다시 읽고 A11:L29 및 데이터 시작 12행을 기준으로 연결했다.
- Chrome에서 네이티브 체크박스·드롭다운 칩·본문 줄바꿈과 담당자 요약을 확인했다. 중간 캡처 시간 초과 후 최종 화면 저장에 성공했다. 복원 후 라이브 셀·수식 재조회와 최종 `team-workspace-final.jpg`를 비공개 증거로 보존했다.

## 연결과 범위

회의 안내 HTML에 공동 편집용 Google 시트 진입 링크를 추가했다. 로컬 HTML은 회의 참고용이며 공동 작업 상태를 저장하거나 서버와 동기화한다고 표시하지 않는다. 기존 검색·질문 펼치기 기능은 유지했다. 로그인·프로필 배포 기록에 맞춰 검증 수치를 서버 132 / 프런트 159 / PostgreSQL 71로 갱신했다.

로컬 안내 서버가 종료돼 있던 것을 확인하고, 루프백(127.0.0.1) 전용 전경 프로세스로 다시 실행했다. 기존 다른 프로세스를 종료하지 않았다. HTML 식별자 중복 없음·협업 링크 3개·검증 수치 반영과 실제 제공 HTTP 200을 확인했다.

시트 권한은 업무 기능과 별도로 확인했다. 사용자 명시적 승인 후 공유 창의 ‘이메일 알림 보내기’를 해제하고 최유정의 편집 권한을 추가했다. 최용우 소유자, 이승현·최유정 편집자로 저장된 것을 Drive 권한 메타데이터로 확인했다. 일반 액세스는 제한됨을 유지했다. 원본 셀 보존 자료와 검증 상세는 비공개 `artifacts/team-workspace-20261104/`에 두며 Git에 넣지 않는다.
