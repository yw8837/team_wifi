## 이번 주 역할

### 멘토 피드백 후 다음 핵심 범위

11/4 추가 피드백에 따라 커뮤니티를 돕는 **출처 기반 챗봇 + 질문 시점 DB/API 조회 + Opik 평가**를 다음 구현 우선순위로 제안한다. 현재 조건 찾기는 재사용할 기능이며 RAG 구현 완료가 아니다. 구체적인 구조·DB 경계·완료 기준·담당 제안은 [커뮤니티 RAG·Opik 설계](2026-11-04-community-rag-opik.md)에 정리했다. 위 128개 분류와 공유 시트 상태는 이전 작업 시점의 기록이며 이 추가 설계로 숫자나 완료 여부를 임의 변경하지 않는다.

| 리드 | 책임 | 공유 업무 |
|---|---|---|
| 최용우 | API·DB·배포 검증, 공개 비교 HTML/구조화 데이터 | T19·T20, T21 API 지원 |
| 최유정 | 조건 선택·상세 비교·추천 카드 UI, 모바일 동선 | T21·T23 |
| 이승현 | 데이터 계보·중복 제거·실제 공동 저장 분석, 지표 해석 | T22·T23 |
| 세 명 | 분석 → 적용 화면 → 검증 → 미완료 설명 리허설 | T24 |

`팀원별 할 일`에는 T19~T24를 추가하고 이름별 체크박스를 지정했다. 기존 T01~T18의 상태·내용·원래 목표는 보존하고 담당/우선순위만 연결했다. 체크박스는 책임 배정이며 해당 팀원이 작업을 수행했다는 증명이 아니다. 팀 검토·리허설 완료는 팀이 확인한다.

## 제안에서 바로 적용하지 않은 전제

- 최근 CI는 성공 상태였다. 오래된 실패 메일을 현재 장애로 설명하지 않는다.
- 현재 공식몰 참고 목록은 가격·재고·개별 SKU 안전인증을 검증한 판매 제안이 아니다. `Product/AggregateOffer` 대신 출처 있는 비교 안내 `Article`과 정적 HTML을 제공한다. 실제 판매 SKU가 확보되면 가격·유효기간·재고·인증 근거를 검증한 후 별도 구조화한다.
- 해외 상품코드를 육아 SKU로 임의 치환하거나 연결 키가 없는 소비자/거래/세션 자료를 합치지 않는다. 실제 공동 저장 ≥5계정을 추천 근거로 사용한다.
- 종료 세션 LightGBM은 실시간 전환 확률이 아니다. 예측 시점과 그때 관측 가능한 특징, 이후 정답을 갖춘 국내 서비스 자료를 확보하기 전에는 연구용으로 유지한다.
- AI 검색 즉시 인용, 78% 함께 구매, 12% 추가 할인, 초대 무료배송 등의 근거 없는 수치를 시연하지 않는다.
