# 원본 요구사항 128개와 현재 커뮤니티 방향 수용 대조

2026-11-06 KST 작성. 이 문서는 G001의 **원본 행 누락 검사** 근거이며, 기능 완료율이나 배포 완료 선언이 아니다. 기준 명세는 [.omc/autopilot/spec.md](../../.omc/autopilot/spec.md), 실행 계획은 [.omc/plans/autopilot-impl.md](../../.omc/plans/autopilot-impl.md), 방향 변경 근거는 [커뮤니티 피드백](2026-11-05-community-feedback.md)다. 병행 통합 중인 작업 디렉터리를 대조했으므로 최종 제품 커밋·CI·실행 산출물 연결은 메인의 최종 검증에서 확정해야 한다.

## 원천과 분모

- 비공개 원천은 artifacts/drive-reference-20261103/requirements.xlsx 및 requirements.csv다. 요구사항 ID가 있는 Excel 2–129행, 128개 고유 ID만 아래 표에 포함했다. CSV 끝의 Figma 메타데이터·빈 행은 요구사항이 아니다. 동반 JSON은 원천 파일 해시, ID 집합·행 대조 결과와 동일한 안전 요약을 보관한다.
- 화면 자료의 346은 설계된 **상태 수**이며 구현된 화면 수가 아니다. [이전 101개 상태표](../build/requirements-status.md)의 R 번호는 별도 역사적 분모다. 101·128·346을 합치거나 어느 하나를 구현 완료 수로 발표하지 않는다.
- 표는 원문을 재게시하지 않고 수용조건을 짧게 바꿔 적었다. 담당자·사적 메모·내부 화면 식별자·원문 예시 인물/시각/금액은 복사하지 않았다. 원문 전체를 대체하는 문서가 아니며 상세 감사는 비공개 원천과 함께 한다.
- 상거래 중심 메인과 과거의 정확한 팔레트·고정 배치는 현재 커뮤니티 중심 동선 및 현행 크림/코럴/코코아 브랜드에 맞춰 대조한다. 이것이 모든 원본 기능의 폐기 승인을 뜻하지는 않는다. 특히 문의 권한·파일 검증·소유권·오류 시 보존은 PG 계약과 독립된 소프트웨어 조건이다.

## 판정과 증거의 경계

**적용·부분**은 현재 커뮤니티/탐색에 적용할 조건의 코드가 있되 원문 전체 수용은 남았다는 뜻이다. **상거래 비활성·부분**은 실제 판매 활성화와 별개로 보존된 소프트웨어의 빈틈을 남긴다. **독립 안전·부분**은 비활성 경로라도 접근·검증 조건을 따로 검사한다. **표현 대체·부분**은 최신 방향이 대체한 표현과 아직 필요한 기능·접근성을 분리한다. 어떤 판정도 “전체 완료”를 뜻하지 않는다.

## G001 누락 검사와 후속 사용

동반 [JSON 대조 데이터](requirements-acceptance-20261106.json)의 원본 ID 집합, Excel 행, Markdown 행을 기계적으로 비교한다. 합격 조건은 원본128개와 정확히 동일한 ID 집합, 중복0, 누락0, 추가0, 원천 행2–129 일치다. 이것은 **행별 처리 판단이 빠지지 않았음**만 증명한다.

최종 메인은 각 실제 수용조건의 실행 로그/스크린샷/API 결과/격리 PostgreSQL 결과와 제품 commit·CI·배포/Android 출처를 이어 붙인다. 아직 남은 업무를 PG·HTTPS·콘솔 할당량 같은 외부 조건 뒤로 숨기거나, 반대로 사업 실체가 없는 실제 결제/배송/사업자 인증을 만들어 성공으로 표시하지 않는다. 장기 사용자·매출·CTR·검색 인용·인간 평가 효과는 별도의 관찰 없이는 결과로 기록하지 않는다.
